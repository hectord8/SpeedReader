# SpeedReader

A lightweight Chrome Manifest V3 extension that displays selected text one word at a time using RSVP (Rapid Serial Visual Presentation).

## Install locally

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this folder.
4. Select text on a webpage and click the SpeedReader toolbar icon.

You can also paste text directly into the popup. The default speed is 300 WPM and can be adjusted from 100 to 1000 WPM.

## Controls

- **Space**: play/pause
- **Left/Right arrows**: previous/next word
- **Up/Down arrows**: increase/decrease speed by 25 WPM
- **Ctrl+Shift+Y** (Cmd equivalent on macOS): capture the current selection and open the reader, where supported by Chrome
